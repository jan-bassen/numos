# hub

The holder-facing app for Numos, where users browse collections, authenticate, and view and interact with their dynamic digital assets.

Built with [Next.js](https://nextjs.org/) and [Drizzle](https://orm.drizzle.team/) for database access.

## Development

From the repo root:

```sh
turbo dev --filter=hub
```

Or from this directory:

```sh
pnpm dev
```

The app runs at [http://localhost:3000](http://localhost:3000).
