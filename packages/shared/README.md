# @repo/shared

Shared code used across the Numos apps — datatypes, schemas, utilities, and the node engine that powers dynamic assets.

## Exports

- `./engine/*` — the node engine
- `./types/*` — shared TypeScript types
- `./schemas/*` — data schemas
- `./validation/*` — validation logic
- `./security/*` — security helpers
- `./errors/*`, `./result/*` — error and result handling
- `./constants/*` — shared constants
- `./utils/*` — common utilities

## Usage

```ts
import { ... } from '@repo/shared/engine/...'
```
